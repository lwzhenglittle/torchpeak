# Community results

Community-contributed benchmark runs, one directory per device: `<slug>/<slug>.json` plus the
generated `<slug>.md` table view. See "Submit your results" in the top-level README for the run
recipe and rules; `scripts/validate_result.py` checks every file in CI.

Measured values here feed `peaks.json` entries: `basis: "measured, see results/community/<slug>/<slug>.json"`.
HTML reports are not stored — they regenerate from the JSON (`meta` + `results`). The `<file>.md`
table views are generated by `scripts/result_to_md.py`; CI fails when they are missing or stale.
